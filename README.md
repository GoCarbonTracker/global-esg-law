# global-esg-law

This repository records ESG-relevant law of 154 places (one folder per ISO 3166-1 alpha-2 code under `register/`, plus EU; as of 2026-11-03) as dated git history. It holds law text only where the matching row in `sources.json` has the verdict `pass`. The repository records what law is in force on a date and says nothing about whether any company complies with it.

The name is wider than what is built. As of 2026-11-03, 154 places have a scope list (EU, GB, IN and US are the pilot, the other ten of the first fourteen are wave 1, and the rest came in waves 2 to 15), listed below, and 1166 watchers in `upkeep/watchers.json` cover every instrument in those lists.

## Look up the law in force on a date

```
python3 tools/law.py <ISO2> <YYYY-MM-DD>
```

Some places hold their laws only as originally published; COVERAGE.md lists them under Not covered, and a lookup there does not include later amendments.

Example: `python3 tools/law.py GB 2023-01-01`. Options: `[--repo PATH] [--ref history] [--lang CODE] [--json]`. In Python: `in_force(iso2, on, repo=ROOT, ref="history", lang=None, detail=False) -> list[dict]`. The lookup reads the `history` branch, which holds one dated commit per record with the text in it. Stayed or enjoined rules count as in force on their date; their `status_note` from `register/<ISO2>/scope.json` is printed with them. `tools/law.py` ships with GEL-01-07; this interface is fixed in the readiness report for that story.

One line per instrument per date: the official-language record. Every other language of the same version is listed under it with its language and kind. `--lang <code>` returns that language's record when the version has one, and otherwise the official record, with a note saying so. `--json` adds a `languages` list to each instrument, the shown record first. The `history` branch must be rebuilt (`python3 tools/build.py --branch history`) before the lookup sees the `Language` trailer; until then every record shows language `-`.

Shape of the output for a version with two official languages and an English translation (ids are placeholders):

```
$ python3 tools/law.py CH 2025-06-01 --lang en
ch-example-act	2025-01-01	translation	Example Act
  de	consolidated
  fr	consolidated
note ch-example-act: showing the en record
$ python3 tools/law.py CH 2025-06-01 --lang it
ch-example-act	2025-01-01	consolidated	Example Act
  fr	consolidated
  en	translation
note ch-example-act: no it record for this version, showing the official record (de)
```

Policy for the lookup (Varun, 2026-11-02): a rule that is stayed or enjoined stays in the in-force list, with the stay in its scope `status_note` and record `message`; an amendment published but not yet in force is an ordinary record dated its in-force date, and the lookup lists it as not yet in force; a circular or notice with no commencement clause takes its issue date as `in_force`.

## Rebuild the history

```
python3 tools/build.py --branch history
```

This builds `history` from scratch from `records/` and replaces the branch if it exists. It is the only build command: once anything under `records/` is tracked by git, a run without `--branch` exits 2 and writes nothing, so commits can no longer land on the checked-out branch by mistake. Records added by `tools/update.py` (see `upkeep/README.md`) are ordinary record files, so the same command rebuilds the branch, upkeep versions included, in `In-force` order.

## Tests

```
python3 -m pytest tests -q
```

Python 3.11 or later, standard library plus git. pytest is the only extra.

## Before going public

The repository went public under the GoCarbonTracker organisation on 2026-11-02 after this checklist passed. Before any further release, run these in order and compare each last line with the expected one:

1. `python3 tools/check_corpus.py` ends with `3071 records checked` (as of 2026-11-03).
2. `python3 tools/publish_gate.py` exits 0.
3. `python3 -m pytest tests -q` ends with `N passed` and no failures.
4. `python3 tools/coverage.py`, then `git diff --quiet COVERAGE.md` exits 0 (no change).
5. `python3 tools/watch.py --dry-run` exits 0 or 1, never 2.
6. Varun says make it public (said 2026-11-02).

`check_corpus.py` refuses any record whose source row is not `pass`. `publish_gate.py` prints every source row and scope entry and exits non-zero if an entry is `pending`, a stored entry has no record or a source row that is not `pass`, or a link-only entry has records.

Size as of 2026-11-02: `du -sh records .git` gives 72M for `records` and 23M for `.git` on a full clone with the `history` branch (2.9M on the cloud session's shallow clone). Decision: law text stays in `main`. `.gitattributes` sets `records/**/*.json -diff` so record files do not render as diffs. Nothing moves to LFS.
